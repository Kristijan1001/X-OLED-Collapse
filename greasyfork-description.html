X OLED Collapse — Black-Out Chrome for X / Twitter

X OLED Collapse folds away everything around the timeline. The left navigation rail, the right-hand trends column, the sticky For you / Following bar, the "What's happening?" composer and the floating corner buttons all collapse to pure #000, leaving the posts centred on a black screen. On an OLED panel those pixels are genuinely off — no glowing sidebar sitting in the same place for hours, no static UI to burn in.

Nothing is deleted. Every collapsed panel is parked just off-screen and slides back the instant you push the pointer into its edge, so navigation, search, trends and posting all stay one flick away.

✨ Features

  • Collapses the whole frame — left nav, right column, tab bar, inline composer and the floating Grok / chat / X Reels buttons, each toggleable on its own.
  • Hover to peek — the left and right panels slide in from their own edge, the tab bar and composer drop down from the top, and each floating corner reveals from the corner it actually sits in.
  • Centred timeline — with the columns gone the feed is measured and centred in the window instead of hugging the left edge.
  • Wider posts — cycle the timeline through 810 / 900 / 1050 / 1200 / 600 / 750 px. Media scales with the column, so images, videos and quote cards stay correct.
  • True black — backgrounds forced to #000, and X's grey 1px hairlines (post separators, column edges, media frames, card outlines) recoloured black rather than removed, so no row changes height.
  • Alt + Q — hide everything, or bring it all back.
  • Remembers everything — every toggle and the timeline width persist across reloads and sessions.

🎛️ Controls

  • Tampermonkey tray menu (the extension icon while on x.com) → a switch for each piece, the width cycle, and Show everything again as a panic button.
  • Alt + Q → hide everything / show everything.
  • Left or right screen edge → the nav rail or the trends column slides in.
  • Top edge → the tab bar and composer come back.
  • Top-right / bottom-right corner → X Reels, and the Grok / chat buttons.

🎨 Defaults

Out of the box everything is hidden, backgrounds and outlines are pure black, the timeline is centred at 810px, and hover peek is on. Any of it can be switched off individually from the tray menu — including peek itself, if you would rather the chrome stayed gone for good.

ℹ️ Notes

  • Works on x.com and twitter.com. Requires Tampermonkey or Violentmonkey.
  • Panels are collapsed, never removed from the page, so X's own keyboard shortcuts, navigation and the post composer keep working normally.
  • The reply box on a post page is deliberately left alone — only the composer on the home timeline is hidden.
  • Elements X gives no stable selector for (the sticky header, the composer, the floating buttons) are found by shape rather than by class name, and re-checked on every DOM change, so they survive X's re-renders and page navigation.
